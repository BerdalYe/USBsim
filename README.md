# USBsim

A USB simulator. Plug in a USB stick. It is wrong. Flip it. Still wrong. Flip it again. Correct.

## Run

Open `index.html` in a browser. No build step.

## Test

```sh
node --test
```

## Files

- `usb.js` – the plug-in logic (three tries, always).
- `index.html` – the page and animations.
- `usb.test.js` – tests for the logic.
